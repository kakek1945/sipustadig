# User Manual Sipustadig

Panduan ini ditujukan untuk pustakawan, guru, siswa, dan kepala sekolah yang menggunakan Sipustadig sehari-hari.

## Masuk Aplikasi

1. Buka halaman login.
2. Masukkan email dan password.
3. Setelah berhasil login, pengguna diarahkan ke dashboard sesuai role.

## Katalog Publik

1. Buka menu Katalog atau halaman `/catalog`.
2. Cari buku berdasarkan judul, pengarang, ISBN, penerbit, atau lokasi rak.
3. Gunakan filter kategori dan ketersediaan.
4. Buka detail buku untuk melihat jumlah eksemplar dan status tiap eksemplar.

## Anggota

Pustakawan dapat:

- Melihat daftar anggota.
- Menambah anggota baru.
- Mengedit data anggota.
- Melihat detail anggota dan histori terkait.
- Memblokir atau membuka blokir anggota.

Status anggota memengaruhi kelayakan peminjaman.

## Buku dan Eksemplar

Pustakawan dapat:

- Menambah dan mengedit data buku.
- Upload cover buku.
- Membuat eksemplar satu per satu.
- Generate banyak eksemplar sekaligus.
- Cetak label QR/kode eksemplar.

Eksemplar dengan status tersedia dapat dipinjam. Eksemplar rusak, hilang, dipinjam, atau dimusnahkan tidak tersedia untuk peminjaman baru.

## Peminjaman

1. Buka menu Peminjaman.
2. Klik Peminjaman Baru.
3. Pilih atau cari anggota.
4. Pilih satu atau beberapa eksemplar tersedia.
5. Periksa ringkasan peminjaman.
6. Klik Simpan.

Sistem membuat nomor pinjam otomatis dan menghitung tanggal jatuh tempo dari pengaturan.

## Perpanjangan

1. Buka detail peminjaman aktif.
2. Isi jumlah hari tambahan.
3. Tambahkan catatan jika diperlukan.
4. Klik Perpanjang.

Peminjaman yang sudah terlambat harus dikembalikan terlebih dahulu.

## Pengembalian

1. Buka menu Pengembalian.
2. Scan atau masukkan kode eksemplar.
3. Sistem menampilkan peminjam, buku, tanggal jatuh tempo, keterlambatan, dan estimasi denda.
4. Klik Proses Pengembalian.

Jika terlambat, sistem membuat denda otomatis sesuai pengaturan.

## Denda

Pustakawan dapat:

- Melihat daftar denda.
- Filter denda berdasarkan status.
- Membayar denda.
- Membebaskan denda dengan alasan wajib.

Status denda: Belum Lunas, Lunas, atau Dihapuskan.

## Laporan

1. Buka menu Laporan.
2. Pilih jenis laporan.
3. Gunakan filter tanggal atau tahun.
4. Klik Export CSV jika perlu.

Jenis laporan mencakup peminjaman, histori, ketersediaan buku, aktivitas anggota, denda, keterlambatan, katalog, laporan bulanan/tahunan, kerusakan, dan buku populer.

## Import Data

1. Buka menu Import.
2. Download template sesuai tipe: anggota, buku, atau eksemplar.
3. Isi file CSV/XLSX dengan header yang sama.
4. Upload file.
5. Jalankan preview terlebih dahulu.
6. Jika valid, upload ulang tanpa mode preview untuk menyimpan data.

Jika ada error, sistem menampilkan laporan baris yang perlu diperbaiki.
